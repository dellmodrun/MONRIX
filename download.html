Two ways to use MONRIX. The browser version needs nothing installed and does the Solana trading. The desktop app does everything else: the Monero and Zcash wallets, the swapping and the VPN. There is no installer for the desktop app yet; you build it from the source code.

Which one is for you

BrowserYou want to try the trading screen now, with the Phantom extension. Nothing to download. Open it »
Desktop, build itYou know what a terminal window is and have run npm install before. Steps are in the next post; it takes a few minutes the first time.
Desktop, waitIf "git clone" means nothing to you, use the browser version for now. A signed installer you can double-click is on the list, and the Beginner's guide will say when it exists.

Code
git clone <repo> monrix && cd monrix npm install # browser mode: site at / and terminal at /app.html npm run dev # desktop (full) npm run desktop npm run desktop:build # src-tauri/target/release/bundle # Windows without administrator rights for VS Build Tools . .\scripts\msvc-env.ps1 npm run desktop

The first Rust build compiles Tauri and its dependencies and takes a few minutes. Rebuilds take seconds. Checks: npm run build and cargo test in src-tauri/.

First run

  1. Settings: initialise the vault with a master password and unlock it.
  2. Settings, Monero: path to monero-wallet-rpc and the daemon address. Vault: start the process, then create or restore a wallet.
  3. Network: paste a WireGuard config and connect, or enable the Tor switch if Tor is running. Run the exit-IP and DNS checks.
  4. Vault, SOL signer: generate or import the trading key and fund it modestly.
  5. Settings, Zcash: RPC URL and credentials for zcashd or zallet.

Data location

Windows%APPDATA%\io.monrix.terminal
Linux~/.local/share/io.monrix.terminal
macOS~/Library/Application Support/io.monrix.terminal
